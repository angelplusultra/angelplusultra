## Currently

**[AnythingLLM](https://github.com/Mintplex-Labs/anything-llm)** &nbsp;<a href="https://github.com/Mintplex-Labs/anything-llm"><img alt="stars" src="https://img.shields.io/github/stars/Mintplex-Labs/anything-llm?style=flat-square&label=&color=E3B341&labelColor=30363D"></a>

An open-source AI application that runs any LLM, any vector database, and your own documents entirely on hardware you control — no API keys required, no data leaving the machine.

Most of my work there lives in the parts users never see:

- **Scheduled Jobs** — an agent automation system that runs recurring AI tasks on a cron, with configurable tool access, full run history, and execution traces.
- **Document embedding pipeline** — re-architected into queued, forked workers so long-running AI workloads stopped blocking the web process, streaming per-document progress back over server-sent events.
- **Model routing** — an engine with editable multi-condition rules that decides which LLM answers a given prompt, spanning schema migrations through the React UI that configures it.

Somewhere north of **100 merged pull requests** and **80+ code reviews** on the project so far, plus a lot of time in the issue tracker reproducing bugs for people I'll never meet.

---

## What I care about

**Local-first AI.** Most AI tooling quietly assumes a network connection and somebody else's GPU. I'm more interested in what runs on your own hardware, and in the engineering that makes local inference feel as good as a hosted API.

**Retrieval that actually retrieves.** RAG is easy to demo and hard to get right. Chunking strategy, embedding choice, and how a vector store behaves under real documents usually matter more than which model you picked.

**Tools that get out of the way.** Terminal-first, keyboard-driven, no ceremony.
